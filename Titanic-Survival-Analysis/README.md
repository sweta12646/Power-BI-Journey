# 🚢 Titanic Survival Analysis Dashboard

## 📌 Overview
This dashboard analyzes the Titanic dataset to understand passenger demographics and factors influencing survival using interactive visualizations.

---

## 🎯 Objectives
- Analyze survival rates
- Compare passenger classes
- Study gender and age distribution
- Explore passenger demographics
- Identify survival patterns

---

## 📊 Dashboard Features
- KPI Cards
- Survival Analysis
- Age Distribution
- Gender Analysis
- Passenger Class Comparison
- Interactive Filters

---

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Excel

---



## 📈 Key Insights
- Compared survival rates by gender.
- Studied age-wise survival distribution.
- Analyzed passenger class impact.
- Identified demographic survival trends.
