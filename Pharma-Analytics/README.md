# 💊 Pharma Analytics Dashboard

## 📌 Overview
The Pharma Analytics Dashboard provides insights into pharmaceutical sales, product performance, and regional business trends to support strategic decision-making.

---

## 🎯 Objectives
- Analyze pharmaceutical sales
- Monitor revenue performance
- Compare regional sales
- Evaluate product performance
- Track important KPIs

---

## 📊 Dashboard Features
- KPI Cards
- Sales Analysis
- Product Performance
- Regional Insights
- Revenue Trends
- Interactive Dashboard

---

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Excel
